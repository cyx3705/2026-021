# HistoryMercury 复用说明

HistoryMercury 对其他项目的稳定交付面是 `z-Publish`。消费者读取其 `module.manifest.json`、`HistoryMercury.dll`、`HistoryMercury.xml`、`SHA256SUMS` 和 `docs/` 中已发布 Markdown；跨项目走 `diana.docs.mercury`。不读取源码、候选包或历史文档。

HistoryMercury 依赖 HistoryVulcan 的公共模块接口。消费者应通过模块发现与清单加载，不应复制 DLL、依赖源码或项目数据目录。

运行包安装到 `%APPDATA%\HistoryVulcan\Modules\HistoryMercury` 后保持不可变；受管快捷方式、状态、缓存和
Explorer 注册备份属于用户数据，统一位于 `%APPDATA%\HistoryVulcan\HistoryMercury`，不属于发布包。

开发和发布入口以根 `project.manifest.json` 为准；当前需求与验证规则位于 `b-Office/current`。
