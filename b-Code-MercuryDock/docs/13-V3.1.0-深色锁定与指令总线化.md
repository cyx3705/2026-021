# MercuryDock V3.1.0：深色锁定与指令总线化

## 更新范围

V3.1.0 是管理页视觉修复与扩展坞指令化更新。管理页与桌面坞锁定单一深色模式；管理页列表
只显示已入坞条目；扩展坞条目统一为总线指令——项目条目的指令形态是新注册的别名指令
`mercury.dock.open`（打开项目目录），并支持把任意总线指令加入为常驻桌面快捷项，扩展坞
由此从"只打开项目"升级为通用快捷方式桌面化入口。16 条 `dock.*` 指令全部保留不变。

## 深色锁定

此前 `DockTheme` 在控件创建时快照宿主 `Shell.Brush.*` 令牌，宿主处于浅色模式时管理页
整页变白、选中行发白。本版本颜色令牌不再解析宿主主题，恒用深色色板；字体与间距与深浅
无关，继续跟随宿主。管理页根容器补铺深色背景，不再透出宿主浅色停靠框底色。

列表选中色统一为淡黄底（`#EADC9E`）配深色文字，聚焦与失焦一致。

## 指令总线化

- 新增别名指令 `mercury.dock.open <项目名或编号>`：经 `IModuleContext.RegisterCommands`
  以服务进程字面名注册（名称允许多级点号），命中即记一次打开并启动项目目录。
- `MercuryDockUiModule` 实现 `IModuleContextAware` 接入宿主总线；Shell 进程的总线自带
  远程转发，桌面坞与管理页执行指令与宿主 CLI 同一条链路。
- 桌面坞项目按钮点击改走 `mercury.dock.open`；总线缺失（旧宿主）或执行失败时回退本地
  直接打开，桌面坞永远能开目录。
- 手动加入的指令项常驻桌面坞项目之后：指令字形无光圈，不参与权重与策略排序，不记用量；
  右键可"移除该指令"。指令项持久化在 state.json 新增 `Commands` 字段，旧状态文件自然兼容。
- 状态目录新增 `MERCURYDOCK_STATE_DIRECTORY` 环境变量改向（烟测隔离用），改向时跳过
  ActiveDock 旧状态迁移。

## 管理页面

- 列表只显示已入坞条目：项目（固定 + 策略选中）与指令项；新增"指令"列显示条目的指令
  文本，项目行为 `mercury.dock.open <项目名>`。"已排除"列与排除行置灰随之移除。
- 右键菜单：刷新常驻；项目行提供"排除"，指令行提供"移除该指令"。被排除项目经加入框
  找回，`dock.include` 命令保留。
- 图钉列：项目行点击切换；指令行恒亮，点击无效（提示"指令项常驻，右键可移除"）。
- "加入扩展坞"改为"指令 + 参数"双输入：指令框默认常驻 `mercury.dock.open`，下拉候选经
  `command.list` 拉取服务侧全量指令（服务不可达时回退本模块静态清单），可删除改输任意
  指令；参数框在打开项目指令下列出工作树未入坞项目（排除项标注排前），其他指令自由输入。
  参数命中工作树项目时走解除排除并固定，其余按自定义指令常驻入坞。

## 验收门禁

1. `dotnet build b-Code-MercuryDock\MercuryDock.csproj -c Release` 0 警告 0 错误。
2. MercuryDock Smoke 全绿：版本 3.1.0、16 条 dock 反射指令、`mercury.dock.open` 别名
   注册、指令文本组装加引号、command.list 解析、指令项加入/去重/移除、工作树根回退。
3. `Publish-MercuryModules.ps1` 候选包通过 manifest 与 SHA-256 静态门禁。
4. 宿主 `module.reload` 后 `module.list` 显示 `MercuryDock 3.1.0`；浅色宿主下管理页仍为
   深色、选中行淡黄；桌面坞点击项目经总线打开目录；加入框可把任意指令钉上桌面坞。

## 版本

本版本统一更新 `MercuryDock.csproj`、`ModuleInfo.Version`、`z-MercuryDock/module.manifest.json`
和 Smoke 版本断言至 `3.1.0`。
