# MercuryDock 3.2.3 列表选中色修复

## 问题

3.2.2 为收紧行距给 `_list` 设了裸 `ItemContainerStyle`（仅 Padding/MinHeight），
盖掉了宿主隐式样式 `Shell.Item.Base`（深色 AccentSoft 选中）。行回退到系统
ListViewItem 模板，选中变成白底，深色页上刺眼且不符合已定规范（淡黄底深字）。

## 修复

`BuildRowStyle` / `BuildRowTemplate`：自绘行模板（`GridViewRowPresenter` + 圆角 Border），
`IsSelected` → `DockTheme.Selection`（淡黄）+ `SelectionText`（深字），
`IsMouseOver` → `Hover`；选中触发器排在悬停之后，选中色优先。

同时补齐失焦选中资源键 `InactiveSelectionHighlightBrushKey` /
`InactiveSelectionHighlightTextBrushKey`（管理列表与 SuggestBox 候选列表），
防止未走自定义模板时仍冒出系统白底。
