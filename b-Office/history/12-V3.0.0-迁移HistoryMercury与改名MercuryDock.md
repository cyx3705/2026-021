# MercuryDock V3.0.0：迁移 HistoryMercury 与改名 MercuryDock

## 更新范围

V3.0.0 是模块归属与身份更新。源码由 `2026-019-Studio工具箱\b-Code-ActiveDock` 迁至
`2026-021-HistoryMercury\b-Code-MercuryDock`，模块名 ActiveDock 改为 MercuryDock，程序集、
命名空间、清单、状态目录与部署槽子目录同步改名。命令前缀 `dock`、管理窗口 ID `dock.manager`、
Explorer 入口 CLSID 与注册标记保持不变，既有 MCP 投影与用户习惯不受改名影响。

发布链路随迁：019 的 `Publish-StudioModules.ps1` 移除 ActiveDock 条目并删除 `z-ActiveDock`
快照；021 以 `b-Code\Publish-MercuryModules.ps1` 单模块脚本产出 `z-MercuryDock` 正式快照。
宿主按 `HistoryVesta\<项目>\z-*` 自动发现，无需宿主侧配置改动。

## 项目库改名回退修复

整库由 `OneHistory-Projects` 改名 `HistoryVesta` 后，`settings.json` 中的 `proj.worktreeroot`
仍指向已不存在的旧目录；`ReadWorktreeRoot` 此前无条件信任配置值，扫描空目录导致活动坞恒为
"暂无活动项目"。本版本为配置值增加存在性校验，失效时回退默认根 `C:\OneHistory\HistoryVesta`，
今后整库再改名也只会回退不会空列表。两份宿主 settings.json 的陈旧 `proj.*` 指针一并修正。

## 管理页面重做

- 删除"保存策略"按钮：最少/最多显示与半衰期在离开输入框或回车时自动保存；跨进程回写跳过
  正在聚焦的输入框。
- 固定/取消固定收进列表首列图钉：已固定全亮、未固定半透明，点击直接切换。
- 按钮条整体删除：刷新、排除、恢复收录移入列表右键菜单；清除该项/全部记录只保留
  `dock.forget` 命令。
- 策略与"加入扩展坞"收进同一个 8px 圆角矩形选项区，与列表、按钮的圆角语言一致。
- 新增"加入扩展坞"：下拉列出工作树中尚未入坞的项目（被排除项排前并标注），加入即解除排除
  并默认固定；被排除项目由此获得界面内找回入口。对应新命令 `dock.add`（指令数 15 → 16）。
- 管理页列表改绑 `AllProjects` 完整扫描结果，被排除行沉底置灰并带"已排除"标记；桌面坞仍用
  不含排除项的 `Projects`。

## 状态迁移

数据目录由 `%APPDATA%\OneHistoryStudio\ActiveDock` 改为 `...\MercuryDock`，首次加载时若新
state.json 缺失而旧文件存在则一次性复制，固定项、排除名单、使用记录与策略全部保留，旧文件
不删。快捷方式文件夹槽位名同步改为 MercuryDock，Explorer 注册在下次刷新时自动重定向。

## 验收门禁

1. `dotnet build b-Code-MercuryDock\MercuryDock.csproj -c Release` 0 警告 0 错误。
2. MercuryDock Smoke 全绿：模块名 MercuryDock、版本 3.0.0、16 条 dock 指令、工作树根回退
   扫描非空。
3. `Publish-MercuryModules.ps1` 候选包通过 manifest 与 SHA-256 静态门禁。
4. 宿主 `module.reload` 后 `module.list` 显示 `MercuryDock 3.0.0`，桌面坞列出当前活动项目，
   管理页图钉、右键菜单与加入扩展坞按上述交互工作。

## 版本

本版本统一更新 `MercuryDock.csproj`、`ModuleInfo.Version`、`z-MercuryDock/module.manifest.json`
和 Smoke 版本断言至 `3.0.0`。019 遗留的 `%APPDATA%\OneHistoryStudio\Modules\ActiveDock` 等旧槽位
残留由用户手动清理，宿主 3.x 不再读取。
