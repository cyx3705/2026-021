# HistoryMercury Project Overview

## Purpose

HistoryMercury provides the HistoryVulcan desktop project dock, its managed Explorer shortcut folder, and project-level command access for the `C:\OneHistory\HistoryVesta` library.

## Current State

- Formal snapshot: `HistoryMercury 4.3.1` in `z-HistoryMercury`.
- Source: `HistoryMercury 4.3.1` in `b-Code-MercuryDock` (owns global shortcut host, double-slash wake, and command workbench UI for HistoryVulcan 3.10.1).
- Completion regression fixed: under a focused domain, short class input such as `proj.` resolves to that domain's registered methods and continues to declared parameter candidates.
- Candidate consumer package: `b-Publish/current/HistoryMercury` after the package gate runs.

## Scope

The module lists active project directories, maintains the dock and its managed shortcuts, exposes the `mercury` three-part command contract, registers the `HistoryVesta 项目` Explorer entry, hosts `GlobalShortcutService` / double-slash registration, and attaches the command catalog/detail workbench to the Vulcan shell. It uses HistoryVulcan public module, UI, and command contracts without duplicating the host command bus.
