# HistoryMercury Project Overview

## Purpose

HistoryMercury provides the HistoryVulcan desktop project dock, its managed Explorer shortcut folder, and project-level command access for the `C:\OneHistory\HistoryClio` library.

## Scope

The module lists active project directories, maintains project and command entries in the dock, resolves Windows shortcut files, exposes the `mercury` command contract, registers the `HistoryClio 项目` Explorer entry, hosts `GlobalShortcutService` / double-slash registration, and describes its frontend pages as data for HistoryAurora to render. It uses the HistoryVulcan public module and command contracts without duplicating the host command bus, and constructs no frontend control of its own.
